# gtld.fr

Site vitrine professionnel de Jean Guillon, consacré au conseil et à l'accompagnement de projets de nouvelles extensions Internet (nouveaux gTLDs et .MARQUE).

## Déploiement Cloudflare Pages

- Framework preset : None
- Build command : laisser vide
- Build output directory : `/` (ou `.` selon l'interface)
- Production branch : `main`
- Domaine personnalisé : `gtld.fr`

Le site est statique : aucun processus de compilation ni dépendance serveur n'est nécessaire.
